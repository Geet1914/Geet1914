### 🚀 Featured Project

<h3>🌊 VarunAI – Intelligent Drainage Management System</h3>

An AI-powered environmental monitoring system designed to analyze
drainage conditions, identify waste and blockage, and prioritize
cleanup activities.

**Key Features:**
- AI-powered image analysis using Google Gemini.
- Environmental monitoring and rainfall information.
- Interactive maps using Leaflet and OpenStreetMap.
- Explainable cleanup priority scoring.
- Before-and-after cleanup verification.

**Technologies Used:**
Next.js | React | TypeScript | Tailwind CSS | Gemini AI | Leaflet

🔗 **Repository:** https://github.com/Geet1914/VarunAI
